# CosmetiStock WEB

Sistema profesional de inventario y ventas.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Docker
- Apache

## Funcionalidades

- Gestión de productos
- Control de inventario
- Gestión de clientes
- Registro de ventas
- Cuentas por cobrar
- Registro de pagos
- Estadísticas
- Historial de actividades
- Alertas de stock
- Exportación e importación de información
- Diseño responsive

## Base de datos

La aplicación utiliza MySQL como sistema de gestión de base de datos.

Las credenciales y configuraciones sensibles se manejan mediante variables de entorno y no se almacenan en el repositorio.

## Despliegue

El proyecto está preparado para ejecutarse mediante Docker y posteriormente desplegarse en Render.
