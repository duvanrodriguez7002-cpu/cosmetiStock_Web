Preguntas frecuentes

¿Cómo registro un producto?

Dirígete al apartado Productos y selecciona la opción para agregar un nuevo producto. Completa la información solicitada y guarda los datos.

¿Cómo puedo modificar un producto?

En el apartado Productos busca el producto que deseas modificar y utiliza el botón Editar para actualizar su información.

¿Cómo registro una venta?

Ingresa al apartado Ventas, selecciona los productos, indica el cliente y la forma de pago y finalmente confirma la venta.

¿Qué ocurre cuando una venta queda pendiente?

La venta queda registrada en Cuentas por Cobrar para que puedas consultar el saldo pendiente y registrar posteriormente los pagos realizados por el cliente.

¿Cómo puedo hacer una copia de seguridad?

Ve a Configuración y selecciona Exportar Base de Datos. El sistema generará un archivo JSON con la información almacenada.

¿Cómo puedo recuperar una copia de seguridad?

En Configuración selecciona Importar Base de Datos y elige el archivo JSON que anteriormente exportaste.

¿Qué hace el modo oscuro?

Permite cambiar la apariencia de CosmetiStock para utilizar una interfaz oscura. La preferencia queda guardada para futuras visitas.

¿Cómo funciona CosmetiStock?

📊 Dashboard

Muestra un resumen general del inventario, ventas, ganancias, alertas y actividad reciente.

📦 Productos

Permite registrar, consultar, editar y eliminar productos, además de controlar cantidades, precios y stock.

👥 Clientes

Permite administrar la información de los clientes registrados en el sistema.

💰 Ventas

Permite crear ventas, seleccionar productos, establecer métodos de pago y controlar los saldos pendientes.

📈 Estadísticas

Presenta información sobre el comportamiento del inventario, ventas, categorías y productos.

⚙️ Configuración

Permite realizar copias de seguridad, importar información, vaciar los datos y personalizar la apariencia del sistema.
